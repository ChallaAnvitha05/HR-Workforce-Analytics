# HR Workforce Analytics

## Project Overview
This project analyzes workforce data using Microsoft Excel, MySQL, and Microsoft Power BI. The dataset was cleaned in Excel, analyzed using advanced SQL, and visualized through an interactive Power BI dashboard to identify employee attrition, satisfaction, performance, salary trends, and departmental insights.

## Tools Used
- Microsoft Excel
- MySQL
- Microsoft Power BI
